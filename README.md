#Эксперимент 1. Накапливаем данные по шагам
1) Расчётный объём данных от шага к шагу увеличивался.
2) Рабочий набор увеличивался одинаково (примерно на 8 MiB) при каждом добавлении.
3) В рабочий набор на Шаге 0 входит память, используемая компьютером для других программ (как например, Windows, другие приложения, системный кэш). Объём элементов (30,52 MiB): Это «чистый» вес полезных данных. Сюда входят исключительно сами элементы, записанные в 4 сохраненных массивах. Рабочий набор (48,66 MiB): память процесса, которая сейчас находится в физической RAM. Это память не только наших массивов, но и память кода, части среды .NET и служебные данные.
4) Для нашего опыта лучше подходит память Prac05 (Объём элементов), а не общая занятая RAM компьютера (Рабочий набор). Общая занятая RAM - это нестабильный показатель, который зависит не только от данных самой программы, но и (согласно разделу 1) от других приложений (например браузер), Windows (внутренние задачи ОС), системный кэш.
